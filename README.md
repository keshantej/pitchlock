# Pitch Lock

A pitch-matching trainer for iPhone that runs as a home-screen web app.

- **Match a note**, **Sing an interval**, and **Echo a phrase** use the microphone, with an adaptive tolerance band from ±50¢ down to ±10¢.
- **Higher or lower** and **Name the interval** train the ear with no mic needed.
- **Tuner** shows a live pitch trace and offers an optional reference drone.
- **Start here** lessons for complete beginners: make a sound, move it higher and lower, hold it steady, find your range, then a first set of matches.
- A live **coach** shows which sound to sing (“oh”, “ah”, “oo”, or a hum) and which way to move (“go higher ↑”, “a touch lower ↓”, “hold it”).

Pitch detection uses YIN on 2×-decimated frames. Everything runs on the device; nothing is recorded or uploaded.

**Install:** open https://keshantej.github.io/pitchlock in Safari, then Share → Add to Home Screen.
